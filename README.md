# Двор на двор: Казань, 1996

Первая публичная тестовая сборка браузерной 3D-игры с онлайн-комнатами.

## Запуск локально
1. Установить Node.js 18 или новее.
2. В каталоге проекта выполнить \`npm install\`.
3. Выполнить \`npm start\`.
4. Открыть http://localhost:8080 на компьютере.
5. Для игры по локальной сети использовать адрес компьютера в сети. Для игры через интернет развернуть сервис на Render.

## Публикация на Render
1. Подключить Render к GitHub.
2. Создать Web Service из репозитория \`pf231rich-rgb/dvor-na-dvor-kazan-1996\`.
3. Render обнаружит \`render.yaml\`. Если настройки вводятся вручную:
   - Runtime: Node
   - Build command: \`npm install\`
   - Start command: \`npm start\`
4. После успешного deploy открыть HTTPS-адрес сервиса. Клиент и WebSocket работают с одного домена; отдельный адрес сервера в игре вводить не нужно.
5. Проверить \`/health\`: ответ должен содержать \`"ok":true\`.

## Управление
- ПК: WASD — движение, J или F — удар, пробел — блок.
- Телефон: экранные кнопки движения, удара и блока.
- Оба игрока вводят одинаковый код комнаты.

## Игровые правила прототипа
- Комната вмещает до 10 игроков.
- Команды автоматически балансируются: красные и синие.
- Удар действует на близкого противника перед персонажем.
- Обычный удар наносит 28 единиц урона, блок снижает его до 8.
- После потери 100 здоровья игрок возрождается через 3 секунды.
- Счёт команд увеличивается за нокаут.

## Честный статус
Это ранняя тестовая версия, а не законченный коммерческий релиз. В ней есть базовая 3D-арена, сетевые комнаты, серверная проверка дистанции и направления удара, здоровье, блок, нокаут и респаун. Пока отсутствуют полноценные модели и анимации, звуки, боты, карта выбора, сохранение статистики, защита от продвинутого читерства и оптимизированная графика для слабых телефонов. Тестирование с двумя игроками нужно провести после публикации сервера.
