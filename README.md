# Двор на двор: Казань, 1996

Браузерный 3D-мультиплеерный прототип в атмосфере Казани 1990-х. Публичная тестовая сборка: https://dvor-na-dvor-kazan-1996.onrender.com/

## Что уже есть
- Комнаты до 10 игроков, автоматическое распределение по красной и синей командам.
- Камера от третьего лица с вращением мышью/свайпом; движение относительно направления камеры.
- Мобильный виртуальный джойстик.
- Удар, блок, здоровье, нокаут и респаун.
- Машины: ВАЗ-2101, 2105, 2106, 2109, ГАЗ-24, ГАЗ-3110, УАЗ-469 и Москвич-2141.
- Посадка водителя и до трёх пассажиров в одну машину; управление автомобилем с сервера.
- Процедурный городской blockout с дворами, панельными домами, гаражами, промзоной, железной дорогой и берегом.

## Управление
- ПК: WASD — движение/управление машиной, мышь — обзор, E — сесть/выйти, J или F — удар, пробел — блок.
- Телефон: джойстик слева; свайп по правой части экрана — обзор; кнопки справа — сесть/выйти, удар, блок.
- За рулём: джойстик вверх/вниз — газ/задний ход, влево/вправо — поворот.
- Для игры вдвоём используйте одинаковый код комнаты, например `DVOR96`.

## Локальный запуск
1. Node.js 18+.
2. `npm install`
3. `npm test`
4. `npm start`
5. Открыть http://localhost:8080.

## Источники для дальнейшей сборки Казани
- OpenStreetMap: https://www.openstreetmap.org/ — дороги, здания и геометрия города; данные распространяются по ODbL, нужна атрибуция и соблюдение условий лицензии.
- Экспорт OSM Казани в GeoJSON: https://osm2cdr.ru/map/rossiya/tatarstan/kazan/geojson/ — городской набор данных; перед интеграцией нужно вырезать нужную область Кировского района и оптимизировать геометрию.
- Архивные фотографии Казани 1990-х, включая Юдино и Аракчино: https://noga.photos/kazan-manifestation-of-the-past
- Исторические фотографии Кировского района: https://e-kazan.ru/news/show/47466
- Дополнительные архивные материалы Татарстана: https://archives.tatar/

## Честный статус
Это **первая тестовая сборка свободного перемещения и совместной езды**, а не законченный релиз уровня GTA III. Текущая карта — процедурный blockout, вдохновлённый Кировским районом, но пока не точная географическая копия улиц Казани. Машины сейчас собраны из собственной игровой геометрии и узнаваемы по типу, но ещё не являются точными 1:1 моделями. Следующий крупный этап — интеграция реальной OSM-геометрии выбранной части района, затем качественные лицензированные модели машин, интерьеры, анимации дверей и более глубокая физика.
