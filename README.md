# Двор на двор: Казань, 1996

Браузерный 3D-прототип с комнатами и WebSocket-синхронизацией игроков.

## Состав
- `index.html` — 3D-клиент, управление с клавиатуры и сенсорного экрана.
- `server.js` — сервер комнат, до 10 игроков; распределение по двум командам до 5 на сторону.
- `package.json` — зависимости Node.js.
- `render.yaml` — шаблон развёртывания сервера на Render.

## Локальный запуск
1. Установить Node.js 18 или новее.
2. В каталоге проекта выполнить `npm install`.
3. Выполнить `npm start`.
4. Открыть `index.html` в браузере.
5. В поле сервера указать `ws://localhost:8080`.

## Публикация
Развернуть этот репозиторий как Web Service на Render. Команды:
- Build: `npm install`
- Start: `npm start`

После развёртывания заменить в клиенте адрес WebSocket на адрес сервиса с протоколом `wss://`. Для публичного доступа сам `index.html` также нужно разместить на статическом HTTPS-хостинге, например GitHub Pages.

## Текущий статус прототипа
Есть 3D-сцена, управление, комнаты, синхронизация координат и визуальные события атак. Это ранний сетевой прототип: пока нет полноценного урона, серверной боевой логики, NPC, анимаций ударов, античита и матчмейкинга. Команды формируются автоматически, но это ещё не законченная соревновательная игра.
